========================================================================
                 FINDMEJOBS.AI - QUICK START INSTRUCTIONS
========================================================================

Follow these simple steps to install all dependencies and run the app.

------------------------------------------------------------------------
STEP 1: Install Dependencies & Setup Playwright
------------------------------------------------------------------------
Open PowerShell or Command Prompt in the project folder and run:

# 1. Install all required Python packages:
.\.venv\Scripts\python.exe -m pip install playwright fastapi uvicorn websockets browser-use langchain-google-genai langchain-openai pydantic

# 2. Install the Playwright Chromium browser binary:
.\.venv\Scripts\python.exe -m playwright install chromium

------------------------------------------------------------------------
STEP 2: Initial Login (Authentication Setup)
------------------------------------------------------------------------
To set up your LinkedIn session and save login cookies:

1. Run the scraper script in headed mode:
   .\.venv\Scripts\python.exe scrape_linkedin.py

2. A Chrome browser window will open.
3. Log in manually with your LinkedIn username and password. 
4. Complete any security checks or verification codes if prompted.
5. Once logged in and viewing your feed, go back to your terminal window.
6. Press [Enter] to let the script run and cache your session. It will close automatically.

------------------------------------------------------------------------
STEP 3: Start the Web Dashboard
------------------------------------------------------------------------
Once authentication is set up, start the web interface:

1. Start the server:
   .\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000

2. Open your web browser and go to:
   http://127.0.0.1:8000
